Discord Integration

Post kills, deaths, loot and raid completions from this group into a Discord channel.

How do I get a webhook URL?

▸
  1. In Discord, open Server Settings for the channel's server.
  2. Go to Integrations → Webhooks.
  3. Click New Webhook, pick the channel it should post to.
  4. Click Copy Webhook URL.
  5. Paste it below and hit Save — GroupScape sends a test message to confirm it works.
