A fork, with thanks

GroupScape is built on groupiron.men

This site started as a fork of groupiron.men and its tracker — the original project for tracking Group Ironman progress in Old School RuneScape. GroupScape widens the scope to groups and parties generally, but the foundation, the design, and a lot of the hard problems already solved come from that project.

If you like what's here, the original is worth checking out and supporting.
